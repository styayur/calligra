使用指南

快速开始集字排版查字与替换 字库碑帖提取字体 文档文件与平台来源与授权故障排查

快速开始

在集字内容框录入文字。选择传统、来源和横排、竖排或方格，然后点击「生成作品」。如果有缺字，纸面会保留对应的空位。

集字与排版

换行可以分句。用每行或每列字数控制折行，在「间距与留白」调整字距、页边距和标点。超过 1000 字时使用长卷。日文竖排按字格排版。

查字与替换

在「查字」输入文字、书家或作品，点击候选加入纸面。要换字，先点击纸面或下方字条中的字，再在右侧点选候选。方向键移动选中字形，Shift 加方向键可加大步幅。

字库安装与导入

离线版本附有开源字体与原帖样本。在「素材」保存的字形与原扫描图留在当前设备和应用的本地存储中，也可用「个人字库」参加作品排版。完整字库可通过本地 API 的导入命令加载。数据来源和导入命令

碑帖图像提取

打开「素材」并选择本机 PNG、JPEG 或静态 WebP。单字可直接调整切框，整页可先自动定位。核对切框的位置与文字后保存。净底效果可调整阈值和留白，修复模式需明确确认。切字使用投影分割，连笔与残损请手工调整。文字由用户确认。

字体制作与下载

当前版本可以使用字体字形集字。生成安装字体功能尚未提供。

DOCX / ODT

当前版本尚未提供 Word 或 OpenDocument 的字体替换。

文件与平台

用「保存项目」下载 JSON，以便在其他设备继续编辑。需要发布图片时使用 PNG，长卷支持 ZIP。Web 离线包请先解压，然后按包内说明在本机启动。

数据来源、许可与署名

在选中字形后可查看来源。发布作品请保留导出的署名清单，确认各来源允许相应用途。改编的 CC BY-SA 材料需遵守相同方式共享条款。

故障排查

缺字时可检查所选传统、字库或书体。如果本机草稿保存失败，请用「保存项目」保存 JSON。如果离线包无法加载字形，请确认通过本地 HTTP 打开。
