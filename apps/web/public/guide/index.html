使用指南

快速开始集字排版查字与替换 字库碑帖提取字体 文档文件与平台来源与授权故障排查

快速开始

在集字内容框输入文字。选择智能混排或中、日、韩书法风格，再生成作品。打开「补字与校勘」核对字形来源、合成部件和待复核位置。只有确认后才会应用改变文字的建议。

集字与排版

换行可以分句。用每行或每列字数控制折行，在「间距与留白」调整字距、页边距和标点。超过 1000 字时使用长卷。日文竖排按字格排版。

查字与替换

在「查字」输入文字、书家或作品，点击候选加入纸面。要换字，先点击纸面或下方字条中的字，再在右侧点选候选。方向键移动选中字形，Shift 加方向键可加大步幅。

字库安装与导入

离线版本附有开源字体与原帖样本。在「素材」保存的字形与原扫描图留在当前设备和应用的本地存储中，也可用「个人字库」参加作品排版。打开「可选字库」安装已核实许可的本机 JSON 分包。同一字库、版本和来源可分批导入，重复字形以来源和图片校验值去重。可按字库禁用或卸载。分包字段为 schema_version: 1、id、name、version、source 和 glyphs。每包最多 256 个标准 Glyph，使用内嵌 PNG 和 SHA-256。完整上游字库也可通过本地 API 的导入命令加载。数据来源和导入命令

碑帖图像提取

打开「素材」并选择本机 PNG、JPEG 或静态 WebP。单字可直接调整切框，整页可先自动定位。核对切框的位置与文字后保存。净底效果可调整阈值和留白，修复模式需明确确认。切字使用投影分割，连笔与残损请手工调整。可选的实验性识别建议需要另外配置本机模型。现代印刷字模型在历史样本上准确识别 0/20。历史碑帖请手工切框并输入文字。建议需逐项确认才可入库。

字体制作与下载

从项目菜单选择「从作品制作字体」，或打开字体工坊并选择字库。核对覆盖、缺字和授权后，在本机 Companion 生成 TTF。OTF、WOFF2 和候选筛选在高级选项中。生成后可以直接交给文档模块。

DOCX / ODT

打开「文档」，选择 DOCX 或 ODT，选用 Calligra 字库、字体工坊生成的字体或本机字体文件。分析覆盖并预览，按需选择标题、正文或段落。导出后在办公软件中检查分页。若要查看实际替换效果，请安装所选字体。

本机处理服务

字体编译和文档转换使用独立的本机 Companion。在桌面打开工作台，安装同一版本源码中的 apps/api/requirements-companion.txt，运行 python -I apps/api/launch_companion.py。在字体、文档或素材页面输入终端显示的连接码。若浏览器请求本地网络权限，请确认访问来源。Android 可使用集字和导出，连接 Companion 请用桌面浏览器。

可选 PDF 使用 --libreoffice 指定本机程序。实验 OCR 需要安装 requirements-ocr.txt 并用 --ocr-model-dir 指定单独获取的官方模型。安装、连接与故障排查

命令行支持 python -m app.services.font_studio calligra-font-request.json font.zip --confirm-private-rights 与 python -m app.services.document_typesetting report.docx font.ttf --output converted.docx。

转换编辑正文中的普通段落、标题、表格和超链接文字。跳过含域、修订或文本框的 DOCX 段落。页眉、页脚、脚注与公式保留，ODT 修订稿需要先完成审阅。输出引用字体，需在阅读设备安装对应字体。可选 PDF 需要本机 LibreOffice。设置 CALLISTUDIO_LIBREOFFICE_PATH 为其可执行文件路径，或使用命令行 --pdf output.pdf --libreoffice 路径。含嵌入对象、外部素材或部分复杂字段的文件不能导出 PDF。请单独核对 PDF 的字体、分页和文字。

文件与平台

用「保存项目」备份 JSON。作品支持 PNG 和混合 PDF。长卷默认导出单个多页 PDF，兼容 PNG ZIP。历史裁片保留原分辨率。通过浏览器安装 PWA，或先下载离线字体再断网使用。Android 可通过 GitHub 正式 Release 检查更新。

数据来源、许可与署名

在选中字形后可查看来源。发布作品请保留导出的署名清单，确认各来源允许相应用途。改编的 CC BY-SA 材料需遵守相同方式共享条款。

故障排查

缺字时可检查所选传统、字库或书体。如果本机草稿保存失败，请用「保存项目」保存 JSON。如果离线包无法加载字形，请确认通过本地 HTTP 打开。
