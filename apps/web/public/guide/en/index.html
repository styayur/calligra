Getting started

Enter text and choose Smart Mix or a Chinese, Japanese or Korean calligraphy preset. Review suggested glyphs and their sources in Glyph Restoration. Confirm editorial substitutions before applying them.

Composition and long scrolls

Use line breaks to divide passages, and change glyph spacing and margins in the layout controls. Use Long Scroll for a larger work, and export the pages as a ZIP. A long scroll preview is kept for the current session.

Find and replace glyphs

Search a character, calligrapher or work under Find glyphs. Add a candidate to the paper. Select a glyph already on the paper to replace it or adjust its size, rotation, position or ink. Arrow keys move it. Hold Shift to take larger steps.

Personal library and packs

Save confirmed glyphs and source scans in Materials. Import only packs with verified provenance and rights. Back up the personal library separately from your projects. Use the Windows migration tool to export both from the retired v0.8.1 application.

Extract glyphs from scans

Choose a PNG, JPEG or static WebP. Draw boxes by hand, or try automatic location and then check the boxes. Confirm the text of each crop. Experimental OCR needs local models. Historical sources require manual review and annotation.

Font Studio

Choose Make a font from this artwork in the project menu, or open Font Studio separately. The local Companion compiles TTF by default. OTF and WOFF2 are in the advanced formats. A generated font can be used in Documents without reuploading it.

DOCX and ODT

Open a DOCX or ODT file and choose a bundled, generated or local font. Review coverage and preview the glyphs. Choose headings, body or paragraph numbers. Install the selected font to inspect the result in your office application. Optional office PDF uses local LibreOffice.

Independent Companion

On a desktop, install apps/api/requirements-companion.txt from the corresponding source version and run python -I apps/api/launch_companion.py. Paste its connection code into Font Studio, Documents or Materials, and grant local network permission if prompted. Optional local OCR needs separately installed model files.

Desktop setup, Windows migration and Companion

Save, install and update

Save the project JSON or export artwork PNG. Install the Web app through your browser. Select Download offline fonts while online to prepare the bundled fonts. On Android, App updates checks GitHub Releases. Download and confirm installation through Android.

Provenance and licences

Inspect the source of every glyph you use. Keep the credits with exported work, and follow the share-alike terms for adaptations of CC BY-SA material.

Troubleshooting

For missing glyphs, review the font, tradition and allowed fallback. If a browser clears its storage, restore your projects and library from backups. Open the offline ZIP through a local HTTP server.
