はじめに

本文を入力し、言語の自動判別か中国書道、日本書道、韓国書芸のいずれかを選びます。字形の補完候補と出典を確認します。校勘で文字を替える場合は、内容を確認してから適用します。

組版と長巻

改行で文を区切り、組版設定で字間と余白を調整します。長い作品には長巻を使い、全ページを ZIP に書き出してください。プレビューは現在のセッションで保持されます。

検索と置き換え

字形検索で文字、書家、作品を探し、候補を用紙に追加します。配置済みの字形を選ぶと、置き換えや大きさ、回転、位置、墨の調整ができます。矢印キーで移動し、Shift で移動量を増やします。

個人ライブラリと追加パック

素材で確認済みの字形と原画像を保存します。出典と利用条件を確認したパックだけを取り込んでください。個人ライブラリとプロジェクトは別々にバックアップします。旧 Windows 版 v0.8.1 のデータは移行ツールで書き出せます。

画像から字形を切り出す

PNG、JPEG、静止 WebP を選びます。枠を手動で作るか、自動検出した枠を確認します。各字の文字を確認して保存してください。OCR の候補は実験機能で、ローカルモデルを使います。歴史資料は手動で切り出して校正してください。

フォント制作

プロジェクトメニューの「作品からフォントを作成」を選べます。ローカルの Companion で TTF を生成します。詳細設定から OTF と WOFF2 も選べます。生成したフォントは文書の組版でそのまま使えます。

DOCX と ODT

DOCX または ODT を開き、同梱フォント、生成したフォント、ローカルのファイルから選択します。字形の収録範囲を確認し、見出し、本文、または段落を選んで書き出します。文書編集ソフトで確認するには、選択したフォントをインストールしてください。

独立 Companion

デスクトップで同じ版のソースにある apps/api/requirements-companion.txt をインストールし、python -I apps/api/launch_companion.py を実行します。表示された接続コードをフォント、文書、素材のいずれかの画面に入力します。必要に応じてローカルネットワークへのアクセスを許可してください。

デスクトップ、Windows 移行と Companion の設定

保存・インストール・更新

プロジェクト JSON を保存するか、作品を PNG に書き出します。ブラウザーから Web アプリをインストールできます。オフラインで使うフォントはオンラインで先にダウンロードしてください。Android のアプリ更新では GitHub Releases を確認し、インストールは Android の画面で承認します。

出典とライセンス

実際に使用する字形の出典を確認します。書き出した作品には出典一覧を添え、CC BY-SA 資料を改変した場合は継承条件に従ってください。

困ったとき

字形が不足するときはフォント、伝統、補完設定を確認してください。ブラウザーデータを消した場合はバックアップから復元します。Web ZIP はローカル HTTP サーバーで開きます。
