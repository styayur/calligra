Calligra 가이드

시작하기조판과 두루마리자형 찾기와 바꾸기개인 라이브러리 및 팩스캔에서 자형 추출글꼴 제작DOCX 및 ODT독립 Companion저장, 설치 및 업데이트출처와 라이선스문제 해결

시작하기

집자 작업실에 텍스트를 입력하세요. 서예 전통과 가로쓰기, 세로쓰기 또는 격자를 선택한 뒤 작품 만들기를 누르세요. 누락된 자형의 위치는 빈칸으로 남습니다. 인터페이스 언어, 텍스트 언어, 자형 전통은 개별 설정입니다.

조판과 두루마리

줄 바꿈으로 구절을 나누고 조판 설정에서 글자 간격과 여백을 조정하세요. 긴 작품은 두루마리로 만들고 모든 페이지를 ZIP로 내보내세요. 미리보기는 현재 세션에 유지됩니다.

자형 찾기와 바꾸기

자형 검색에서 문자, 서예가 또는 작품을 찾아 용지에 추가하세요. 배치된 자형을 선택하면 자형을 바꾸거나 크기, 회전, 위치와 먹을 조절할 수 있습니다. 화살표 키로 이동하고 Shift를 누르면 이동 거리가 늘어납니다.

개인 라이브러리 및 팩

소재에서 확인한 자형과 원본 스캔을 저장하세요. 출처와 이용 조건을 확인한 팩만 가져오세요. 라이브러리와 프로젝트를 따로 백업하세요. 이전 Windows v0.8.1 데이터는 마이그레이션 도구로 내보낼 수 있습니다.

스캔에서 자형 추출

PNG, JPEG 또는 정적 WebP를 선택한 뒤 자르기 상자를 직접 그리거나 자동 위치를 검토하세요. 자형마다 텍스트를 확인하고 저장하세요. 실험적 OCR에는 로컬 모델이 필요합니다. 역사 자료는 직접 자르고 교정하세요.

글꼴 제작

권한을 확인한 개인 자형이나 현재 작품의 자형을 선택하세요. 대상 텍스트를 입력하면 지원 범위를 확인할 수 있습니다. Companion은 TTF, OTF, WOFF2와 라이선스 목록을 만듭니다. 명령줄 요청 파일을 따로 저장할 수도 있습니다.

DOCX 및 ODT

DOCX 또는 ODT와 로컬 TTF 또는 OTF를 선택하세요. 지원 범위와 변환할 문단을 검토하고 Companion에서 변환하세요. 문서 편집기에서 페이지 나누기를 확인하고, 문서를 읽을 기기에 글꼴을 설치하세요. PDF에는 LibreOffice가 필요합니다.

독립 Companion

데스크톱에서 같은 버전의 소스에 있는 apps/api/requirements-companion.txt를 설치하고 python -I apps/api/launch_companion.py를 실행하세요. 표시된 코드를 글꼴, 문서 또는 소재 화면에 입력하세요. 브라우저가 요청하면 로컬 네트워크 권한을 허용하세요.

데스크톱 설정, Windows 마이그레이션 및 Companion

저장, 설치 및 업데이트

프로젝트 JSON을 저장하거나 작품을 PNG로 내보내세요. 브라우저에서 웹 앱을 설치할 수 있습니다. 오프라인 작업 전 온라인에서 글꼴을 받아 두세요. Android 앱 업데이트 메뉴에서 GitHub Releases를 확인하고 시스템 화면에서 설치를 승인하세요.

출처와 라이선스

사용한 모든 자형의 출처를 확인하고 내보낸 작품에 출처 목록을 남기세요. CC BY-SA 자료를 수정한 경우 동일한 조건으로 공유하세요.

문제 해결

누락 자형이 있으면 글꼴, 서예 전통 및 보완 설정을 확인하세요. 브라우저 데이터를 지웠다면 백업에서 복원하세요. Web ZIP은 로컬 HTTP 서버로 여세요.
