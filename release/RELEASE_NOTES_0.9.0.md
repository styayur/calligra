# Calligra v0.9.0

## Korean composition

Choose Korean separately from Chinese and Japanese. Nanum Brush Script and Nanum Pen Script provide digital Korean calligraphy and handwriting. Source Han Serif KR supplies Korean-region Hanja coverage. Choose it explicitly to explore the Jamo included by the typeface. The historic Hangul fixture establishes support for its exact tested sequence.

## Interface languages

Choose Simplified Chinese, Japanese, Korean or English. Calligra uses the browser or device language by default and remembers manual choices. The UI preference leaves project text and glyph tradition independent.

## Web and Android

On desktop, open the [PWA](https://styayur.github.io/calligra/) or serve the Web ZIP locally. Install the app through your browser and prepare the bundled fonts while online. Projects and personal libraries remain in browser storage. Existing Windows Electron users can export drafts and libraries with the [Windows migration tool](https://github.com/styayur/calligra/blob/v0.9.0/docs/PWA_COMPANION.md). Historical installers remain on the v0.8.1 release.

In Android, use **App updates** to check official GitHub Releases. The app compares versions and verifies the SHA-256, APK package, and existing signing identity before handing off installation to Android. Download and install are independent user actions. Automatic checks at launch are opt-in.

## Optional desktop Companion

Use the independent Python Companion for font compilation, DOCX/ODT and optional PDF conversion, and experimental OCR. The browser connects to loopback using a session connection code. See the [setup and migration guide](https://github.com/styayur/calligra/blob/v0.9.0/docs/PWA_COMPANION.md). Android retains the offline core workbench.

Historical OCR suggestions require manual review. Earlier historical OCR fixtures scored 0/20 for recognition and 0/6 for automatic localization. Manual box drawing, correction and private-library entry remain available.

The app code is GPL-3.0-or-later. The download contains licence notices and a provenance manifest for fonts, historical samples, and bundled software. Check the Web ZIP and APK against the attached SHA256SUMS.txt before installing.
