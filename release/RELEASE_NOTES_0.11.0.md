# Calligra v0.11.0

- The workbench opens in Smart Mix. Chinese, Japanese and Korean calligraphy each have their own preset. Regional choices, historical forms and cross-tradition exploration are in the advanced controls.
- Glyph restoration prioritizes documented same-work or same-author matches and tracks their sources. The initial IDS and editorial catalogues cover a limited set of cases. Character changes require confirmation. Unresolved readings and their edit history stay in the project.
- Open Font Studio directly from the current composition. Inspect exclusions and coverage, compile with the local Companion, and use the resulting font in Documents. TTF is the default. OTF and WOFF2 are available in advanced formats.
- In Documents, pick a bundled font or a Font Studio result, review coverage and choose headings, body text or paragraph ranges. The local Companion rewrites supported DOCX/ODT objects without uploading the document. The preview shows proposed glyphs. Your office application recalculates pagination.
- The workbench exports PNG and hybrid PDF. Long Scroll defaults to a single multipage PDF, with PNG ZIP available. Vector outlines and native-resolution source images stay separate, and the PDF carries glyph text, attribution and restoration records. The archival preset preserves sources and images. PDF/A conformance and accessibility tagging are outside this release.
- Calligra uses a new bird-track icon. The Android app retains its package identifier and production signing identity. Desktop users can install the PWA or serve the offline Web ZIP. Keep project and personal-library backups before moving to a new site origin or browser profile.

Historical OCR remains an optional experimental feature. Review all transcriptions before using them. [Source and rights records](../docs/DATA_SOURCES.md) · [Historical OCR results](../docs/HISTORICAL_OCR.md) · [Companion setup](../docs/PWA_COMPANION.md)
